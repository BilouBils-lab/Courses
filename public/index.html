Ajouter avec Siri

Créez une fois ce raccourci dans l'app Raccourcis de l'iPhone, puis dites : « Dis Siri, ajoute aux courses ». Siri vous demande quoi ajouter, et les articles arrivent dans la liste partagée.

  1. Ouvrez l'app Raccourcis, touchez + en haut à droite, puis renommez le raccourci Ajoute aux courses (c'est la phrase à dire à Siri).
  2. Ajoutez l'action Demander une entrée. Type : Texte. Question : Qu'est-ce que j'ajoute ?
  3. Ajoutez l'action Texte et collez-y :
    Puis effacez le mot TEXTE (en gardant les guillemets autour) et remplacez-le par la variable Entrée fournie, proposée au-dessus du clavier.
  4. Ajoutez l'action Obtenir le contenu de l'URL et collez cette adresse :
    Touchez la flèche ⌄ pour afficher les options :
    • Méthode : POST
    • En-têtes : ajoutez Content-Type avec la valeur application/json
    • Corps de la requête : Fichier, puis choisissez la variable Texte
  5. Facultatif : ajoutez l'action Énoncer le texte avec C'est noté.

Cette adresse contient le code de votre liste : ne la partagez qu'avec votre compagne. Elle peut aussi ouvrir cet écran depuis son téléphone pour créer son raccourci.
